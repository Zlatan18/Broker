# Đề xuất phối hợp xử lý danh mục

Website trình bày quy trình phối hợp giữa phân tích kỹ thuật, chăm sóc tài khoản và nghiên cứu cổ phiếu chiến lược; đồng bộ chart và kế hoạch trên FireAnt.

Trang tĩnh trong `index.html`, không cần cài đặt hay build.

## Bật GitHub Pages

Settings → Pages → Build and deployment:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

Bấm **Save**. Khi triển khai hoàn tất, GitHub hiển thị đường dẫn website tại trang Pages.
